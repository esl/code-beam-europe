Luca Succi is a Software Developer at Dipl.Phys. Peer Stritzinger GmbH, working where Erlang/BEAM meets embedded systems, robotics, edge computing and critical infrastructure. He is the creator of ROSiE, an Erlang approach to connecting ROS/ROS2 robotics with BEAM-style distribution, fault tolerance and hot code upgrades, which he presented at Code BEAM Europe. At Stritzinger, Luca was the primary investigator for the TARGET-X 5G/6G edge robotics experiment and collaborates on INDIGO-FIDAL and RESCALE, with work spanning ROS2 connectivity, secure edge systems, digital twins, supply-chain security and railway infrastructure. He contributes heavily to the GRiSP ecosystem and is the main contributor to Braid, an Erlang library and CLI for creating and testing distributed node clusters that grew out of the TeraFlow research project. He also works close to the BEAM itself, including GRiSP's ARM32 JIT effort, turning low-level systems challenges into running software on real hardware.
